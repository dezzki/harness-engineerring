## 🏗️ PHASE F1 — Course (Aug 13 → Sep)

### Daily (set, then check off each day)
- [ ] 1. Daily English block — 30 min with a *method* (listen + speak aloud, not just reading)
- [ ] 2. Base-engineering block — 1 problem / 1 topic (DS-algo or language fundamentals)
- [ ] 3. Course work — lecture(s) read OR project session (~2–3 hrs)
- [ ] 4. Evening review — 5 min: what did I learn today? (one line in your notes)

### Weekly (each Sunday)
- [ ] Two lectures absorbed (or the week's structured equivalent)
- [ ] One lecture-code demo actually run (`npx tsx …/code/…`)
- [ ] One session on the current project (`/Harness/Projects/project-NN`)
- [ ] Grades check — pushed ≥70% in every subject? (MEXT requires it)
- [ ] English check — logged speaking time ✔ | new words learned ✔
- [ ] One social post / DM in the building-in-public thread *(optional but compounding)*

### Phase Gates (all required to advance)
- [ ] **L01 + L02** read and understood (failure modes + 5 subsystems)
- [ ] **P01 complete:** weak vs. strong run recorded, metrics compared, dirs archived
- [ ] **L03 → L12 + P02 → P06** all complete in order
- [ ] **L13, L14 + P07, P08** read (docs-only)
- [ ] `audit-harness.sh` passes on your final project repo
- [ ] 14 lecture folders each contain your notes or a status stamp

### Course rhythm reminder
- [ ] Weak/strong runs in **isolated dirs** — never both present (contamination rule)
- [ ] Evidence **reset** before the strong run
- [ ] Treat each project as an **experiment**, not "make starter = solution"
